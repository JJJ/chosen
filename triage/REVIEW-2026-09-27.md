The sweep removed **68** reports from the actionable list as invalid,
duplicate, support-only, or declined. Another **26** are already covered by
the fork. **12** need information or an environment we do not currently have.
That leaves **73** issues worth investigating: 37 feature or maintenance
candidates and 36 potential bugs needing reproduction. These are not all ready
to implement.

Examples of the cull:

- [#3156](https://github.com/harvesthq/chosen/issues/3156) is unrelated
  promotional HTML; [#3148](https://github.com/harvesthq/chosen/issues/3148)
  contains only the unfilled issue template.
- [#3080](https://github.com/harvesthq/chosen/issues/3080) and
  [#2947](https://github.com/harvesthq/chosen/issues/2947) repeat the
  overflow-clipping problem tracked in
  [#86](https://github.com/harvesthq/chosen/issues/86).
- [#3104](https://github.com/harvesthq/chosen/issues/3104) passes invalid
  arguments to jQuery's `trigger`; the reported exception comes from the
  integration code.
- [#841](https://github.com/harvesthq/chosen/issues/841) asks Tab to select
  a result, which would interfere with normal focus navigation.
- [#5](https://github.com/harvesthq/chosen/issues/5) is now covered by the
  opt-in `create_option` setting, which adds values to the native select.
  [#2507](https://github.com/harvesthq/chosen/issues/2507) is covered by
  `display_selected_value`, and
  [#2611](https://github.com/harvesthq/chosen/issues/2611) by
  `inherit_option_classes`.

The next focused checks should be
