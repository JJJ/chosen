# Support

For setup questions and integrations, use [GitHub Discussions](https://github.com/JJJ/chosen/discussions).
Check the [live demos](https://jjj.github.io/chosen/) and [options reference](https://jjj.github.io/chosen/options.html) for usage examples.

Use [GitHub Issues](https://github.com/JJJ/chosen/issues/new/choose) for reproducible
bugs and focused feature requests. Include your Chosen version, jQuery or
Prototype version, browser, operating system, relevant options, and a small
reproduction.

For potential vulnerabilities, use the [security reporting instructions](SECURITY.md).
For behavior in the original project, check the
[Harvest issue tracker](https://github.com/harvesthq/chosen/issues) before opening
a report in this fork. This fork has diverged, so reproduce the issue here too.
