# Security policy

## Supported versions

Security fixes target the latest release of this maintained fork. Older releases
and the original Harvest repository are not maintained here. If a fix can be
backported safely, the maintainers may choose to do so.

## Report a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/JJJ/chosen/security/advisories/new)
for a suspected vulnerability in `JJJ/chosen`. Do not open a public issue or
pull request with exploit details before the maintainers have had a chance to
review the report.

Include the affected version or commit, a minimal reproduction, expected and
actual behavior, and any known impact. The maintainers will review the report
and coordinate a fix and disclosure through the private advisory. If the report
is about another project, contact that project's maintainers instead.
